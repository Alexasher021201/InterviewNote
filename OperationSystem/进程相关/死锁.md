# 死锁必要条件

1. 互斥：每个资源要么分配给一个进程，要么就是可用
2. 等待与占有：已经得到某个资源的进程可以再次申请新的资源
3. 不可抢占：已经分配给一个进程的资源，不可以被抢占，只能等他自己显示的释放
4. 环路等待：存在两个或以上的进程组成一个环路，都在等待对方释放资源来供自己使用

# 如何应对死锁

1. 鸵鸟策略：  
直接无视死锁，因为死锁处理的代价很大。鸵鸟策略这种不采取任务措施的方案会获得更高的性能。当发生死锁时不会对用户造成多大影响，或发生死锁的概率很低，可以采用鸵鸟策略。大多数操作系统，包括 Unix，Linux 和 Windows，处理死锁问题的办法仅仅是忽略它。
2. 死锁检测与恢复：  
当死锁出现时，尝试排查，例如寻找是否出现环路，
    - 死锁恢复：
        - 利用抢占恢复
        - 利用死锁恢复
        - 通过杀死进程恢复
3. 死锁预防：  
    - 破坏互斥条件
    - 破坏占有条件：所有进程在执行前必须确保能够请求到他所需要的所有资源。
    - 破坏不可抢占条件：
    - 破坏环路等待条件：给资源编号，进程只能按照编号顺序申请资源。

# 死锁避免
