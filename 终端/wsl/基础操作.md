# WSL 基础指令复习笔记

## 1. WSL 是什么？

WSL（Windows Subsystem for Linux）允许我们直接在 Windows 中运行 Linux 环境。

例如 Windows 中可以同时存在多个 WSL 发行版：

```text
Windows
│
├── Ubuntu              ← 日常 Linux 开发
│
├── Ubuntu-24.04        ← 另一个 Linux 发行版
│
└── docker-desktop      ← Docker Desktop 内部使用
```

注意：

> `Ubuntu` 和 `docker-desktop` 是两个独立的 WSL 发行版。

`docker-desktop` 是 Docker Desktop 内部使用的精简 Linux 环境，不推荐把它当作日常开发环境。

---

# 2. 查看当前安装的 WSL

在 **PowerShell / CMD** 中：

```powershell
wsl -l -v
```

完整写法：

```powershell
wsl --list --verbose
```

例如：

```text
NAME              STATE           VERSION
* Ubuntu            Running         2
  docker-desktop    Running         2
```

含义：

- `NAME`：WSL 发行版名称
- `STATE`：当前运行状态
- `VERSION`：WSL 版本
- `*`：默认 WSL 发行版

因此：

```text
* Ubuntu
```

表示执行：

```powershell
wsl
```

默认进入 Ubuntu。

---

# 3. 进入 WSL

## 进入默认 WSL

```powershell
wsl
```

例如默认发行版是 Ubuntu：

```text
PowerShell
    ↓
wsl
    ↓
Ubuntu
```

---

## 指定进入 Ubuntu

```powershell
wsl -d Ubuntu
```

`-d` 可以理解为：

```text
-d = distribution
```

即指定 Linux 发行版。

如果名称是：

```text
Ubuntu-24.04
```

则：

```powershell
wsl -d Ubuntu-24.04
```

---

# 4. 设置默认 WSL

例如设置 Ubuntu 为默认发行版：

```powershell
wsl --set-default Ubuntu
```

或者：

```powershell
wsl -s Ubuntu
```

然后检查：

```powershell
wsl -l -v
```

看到：

```text
* Ubuntu
```

说明设置成功。

以后直接：

```powershell
wsl
```

就会进入 Ubuntu。

---

# 5. 退出 WSL

在 Linux Shell 中：

```bash
exit
```

例如：

```text
Ubuntu
  ↓
exit
  ↓
PowerShell
```

注意：

```bash
exit
```

只是退出当前 Shell，并不等于彻底关闭所有 WSL 虚拟机。

---

# 6. 关闭 WSL

关闭所有正在运行的 WSL：

```powershell
wsl --shutdown
```

例如：

```text
Ubuntu          Running
docker-desktop  Running

        ↓

wsl --shutdown

        ↓

Ubuntu          Stopped
docker-desktop  Stopped
```

适用于：

- WSL 卡住
- Docker / WSL 出现异常
- 想完全重启 WSL
- 修改某些 WSL 配置后需要重启

---

# 7. 安装 Ubuntu

查看可以安装的发行版：

```powershell
wsl --list --online
```

安装 Ubuntu：

```powershell
wsl --install -d Ubuntu
```

也可以尝试 Web 下载：

```powershell
wsl --install -d Ubuntu --web-download
```

安装完成后第一次启动通常需要创建：

```text
Linux username
Linux password
```

# 8. WSL1 和 WSL2

查看版本：

```powershell
wsl -l -v
```

例如：

```text
NAME       STATE       VERSION
Ubuntu     Running     2
```

说明 Ubuntu 使用：

```text
WSL 2
```

将 Ubuntu 设置成 WSL2：

```powershell
wsl --set-version Ubuntu 2
```

设置以后新安装的 Linux 默认使用 WSL2：

```powershell
wsl --set-default-version 2
```

一般开发和 Docker 环境优先使用 **WSL2**。

# 9. Windows 与 WSL 路径对应关系

这是非常重要的知识点。

Windows：

```text
C:\
```

在 Ubuntu WSL 中：

```bash
/mnt/c/
```

Windows：

```text
D:\
```

对应：

```bash
/mnt/d/
```

例如 Windows 项目：

```text
D:\项目\agentProject\DD_Rag
```

在 Ubuntu 中通常可以：

```bash
cd /mnt/d/项目/agentProject/DD_Rag
```

---

## 示例

Windows：

```text
D:\apiKey\chatgpt\key.txt
```

Ubuntu WSL：

```text
/mnt/d/apiKey/chatgpt/key.txt
```

因此可以：

```bash
cd /mnt/d/apiKey/chatgpt
```

然后：

```bash
vim key.txt
```

# 10. 从 WSL 打开 Windows 文件夹

在 Ubuntu 中：

```bash
explorer.exe .
```

`.` 表示：

```text
当前目录
```

例如：

```bash
cd /mnt/d/项目
explorer.exe .
```

Windows 文件资源管理器就会打开：

```text
D:\项目
```

这是一个非常实用的命令。

# 12. 为什么 docker-desktop 没有 apt？

如果终端显示：

```text
docker-desktop:/#
```

然后执行：

```bash
apt
```

出现：

```text
-sh: apt: not found
```

通常不是 WSL 坏了。

而是因为：

```text
docker-desktop
```

是 Docker Desktop 自己使用的内部 Linux 环境，非常精简。

它与：

```text
Ubuntu
```

不是同一个系统。

因此：

```text
docker-desktop
├── Docker 内部使用
├── 非常精简
├── 可能没有 apt
├── 可能没有 sudo
└── 不建议作为开发环境
```

而：

```text
Ubuntu WSL
├── 正常 Linux 开发环境
├── apt
├── sudo
├── vim
├── git
└── Java / Python / Node 等开发工具
```

---

# 13. docker-desktop 和 Ubuntu 的关系

可以简单理解成：

```text
Windows
│
├── WSL
│   │
│   ├── Ubuntu
│   │     └── 给我们开发使用
│   │
│   └── docker-desktop
│         └── Docker Desktop 自己使用
│
└── Docker Desktop
```

因此不要把：

```text
WSL = docker-desktop
```

它们混为一谈。

准确来说：

> docker-desktop 只是运行在 WSL2 架构上的一个特殊发行版。

# 14. 常用 Linux 基础命令

进入 Ubuntu 后，这些命令非常高频。

```bash
pwd
```

```bash

```



```text

```

```powershell

```

# 18. 核心理解

最重要的是理解下面这张关系图：

```text
Windows
│
├── PowerShell
│      │
│      └── wsl -d Ubuntu
│               ↓
│
├── WSL2
│   │
│   ├── Ubuntu            ← 我们日常开发
│   │
│   └── docker-desktop    ← Docker Desktop 内部使用
│
├── C:\
│     ↕
│   /mnt/c/
│
└── D:\
      ↕
    /mnt/d/
```

记住三句话：

1. **WSL 是 Windows 运行 Linux 的环境。**
2. **Ubuntu 和 docker-desktop 是两个不同的 WSL 发行版。**
3. **日常 Linux 开发进入 Ubuntu，不要进入 docker-desktop。**
