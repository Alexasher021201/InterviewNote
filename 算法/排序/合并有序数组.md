# LeetCode 88 合并两个有序数组——错误总结

## 1. 合并后没有处理剩余元素

### 错误
比较过程中，其中一个数组遍历结束后，没有将另一个数组的剩余元素加入结果。

导致 `list.size()` 小于 `m + n`，最终执行：

```java
list.get(k)
```

时发生下标越界。

### 注意
合并两个有序数组时，要记得最后进行**收尾处理**：

```java
while (i < m) {
    // 处理 nums1 剩余元素
}

while (j < n) {
    // 处理 nums2 剩余元素
}
```

---

## 2. 错误使用嵌套 while，导致死循环

### 错误

原本写成：

```java
while (i < m) {
    while (j < n) {
        ...
    }
}
```

当 `j == n` 时，内层循环无法进入，而外层的 `i` 又不会变化，导致：

```text
i < m 永远成立 → 死循环 → 超出时间限制
```

### 注意

两个数组同时进行双指针遍历时，应该写：

```java
while (i < m && j < n) {
    // 比较 nums1[i] 和 nums2[j]
}
```

**写 while 时一定检查：循环体执行后，控制循环的变量是否一定有机会发生变化。**

---

## 3. 混淆 `null` 和空数组

### 错误

```java
if (nums2 == null)
```

无法判断：

```java
nums2 = []
```

因为 `[]` 并不是 `null`。

### 注意

```java
nums2 == null       // 数组对象不存在
nums2.length == 0   // 数组存在，但长度为 0
```

本题实际上不需要单独判断空数组，正确的循环条件自然可以处理 `n == 0`。

---

## 核心模板

以后遇到**两个有序数组双指针合并**，记住：

```java
// 1. 两边都有元素：比较
while (i < m && j < n) {
    ...
}

// 2. nums1 收尾
while (i < m) {
    ...
}

// 3. nums2 收尾
while (j < n) {
    ...
}
```

### 本题重点

> **双指针合并 = 同时遍历 + 剩余元素收尾。**

同时要特别警惕：

- `while` 中指针不变化 → 可能死循环
- 结果集合长度不足 → `get()` 可能越界
- `null` 和空数组 `[]` 是两个概念
