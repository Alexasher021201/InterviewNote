# LeetCode 1520：最多的不重叠子字符串

## 1. 题目核心

要求找到尽可能多的**互不重叠子串**。

关键限制：

> 如果子串包含字符 `x`，那么 `x` 在整个字符串中的所有出现位置，都必须包含在这个子串中。

例如：

```text
a b a c b
0 1 2 3 4

a 的初始范围：[0,2]
```

但是 `[0,2] = "aba"` 中出现了 `b`，而 `b` 还出现在下标 `4`：

```text
[a b a] c b
   ↑       ↑
```

所以必须扩展成：

```text
[a b a c b]
0---------4
```

```java
Map<Character, int[]> pos = new HashMap<>();

s = "adefaddaccc"

d → [1,6]
e → [2,2]
f → [3,3]
c → [8,10]
```

## 3. 最重要：为什么需要扩展区间？

如果当前区间：

```text
[l -------- r]
```

扫描里面的字符 `x`，发现：

```text
x → [l_t, r_t]
```

如果：

```text
l_t < l
```

说明左边还有 `x`：

```text
x ... [ ... x ... ]
↑
l_t
```

必须：

```java
l = l_t;
```

同理，如果：

```text
r_t > r
```

说明右边还有 `x`：

```text
[ ... x ... ] ... x
                  ↑
                 r_t
```

必须：

```java
r = r_t;
```

### 核心思想

> 区间包含某字符 → 必须包含该字符的完整范围 → 新范围里又可能出现其他字符 → 继续扩展。

直到区间不能再扩大。

## 4. 我的疑惑：`l/r` 和 `nl/nr` 到底是什么？

不要混在一起：

```text
l、r   = 当前区间的真正边界
nl、nr = 负责检查区间的扫描指针
```

记忆：

> **`l/r` 决定地盘有多大，`nl/nr` 决定检查到哪里。**

---

## 5. 这两行是什么意思？

```java
while (nl >= l || nr <= r) {
    int i = (nl >= l) ? nl : nr;
```

### 第一行

```java
nl >= l || nr <= r
```

表示：

> 左边或者右边只要还有没检查的位置，就继续扫描。

使用 `||` 是因为：

```text
左边检查完了，但是右边可能还没结束
```

或者区间扫描过程中又向左/右扩展了。

---

### 第二行

```java
int i = (nl >= l) ? nl : nr;
```

是三元运算符，相当于：

```java
int i;

if (nl >= l) {
    i = nl;
} else {
    i = nr;
}
```

意思：

> **左边还有位置 → 优先检查左边；否则检查右边。**

如果扫描时 `l` 突然向左扩展：

```text
新l ------ 原l -------- r
             ↑
            nl
```

那么 `nl` 会把新扩展出来的左侧区域补查掉。

## 6. 找完合法区间后：为什么按右端点排序？

```java
valid.sort((a, b) -> a[1] - b[1]);
```

按照：

```text
right 从小到大
```

排序。

原因：

> **优先选择结束得早的区间，给后面的区间留下更多空间。**

例如：

```text
A: [----------------]

B:   [---]
C:        [---]
D:             [---]
```

选 A 可能只能得到 1 个。

而选择结束更早的小区间：

```text
[B] [C] [D]
```

可以获得更多互不重叠区间。

这是经典的**区间贪心**。

---

## 7. 我的疑惑：`end = -1` 是什么？

```java
int end = -1;
```

`end` 表示：

> **上一个已经选择的区间的右端点。**

初始化 `-1` 是因为字符串最小下标为 `0`：

```text
任意合法 left >= 0

所以：

left > -1
```

第一个区间可以正常被选择。

---

## 8. 为什么判断 `left > end`？

```java
if (left > end)
```

表示当前区间必须在上一个区间之后：

```text
上一个：
[2----4]
      ↑
     end

当前：
          [6----8]
           ↑
          left

6 > 4
```

因此两者不重叠。

如果：

```text
[2------5]
     [4------8]
      ↑
     left

4 > 5 ❌
```

说明发生重叠，不能选择。

## 9. 为什么是 `substring(left, right + 1)`？

Java：

```java
s.substring(start, end)
```

范围是：

```text
[start, end)
```

**不包含 `end`。**

但我们的区间是：

```text
[left, right]
```

包含 `right`。

所以：

```java
s.substring(left, right + 1);
```

例如：

```text
abcdef
012345

想取 [2,4] → "cde"

substring(2, 5)
```

## 10. 最后的贪心模板

```java
valid.sort((a, b) -> a[1] - b[1]);

List<String> ans = new ArrayList<>();
int end = -1;

for (int[] interval : valid) {
    int left = interval[0];
    int right = interval[1];

    if (left > end) {
        ans.add(s.substring(left, right + 1));
        end = right;
    }
}
```

理解成：

```text
按结束位置排序
      ↓
从前往后检查
      ↓
left > end ?
  ↓       ↓
 YES      NO
  ↓       ↓
选择     跳过
  ↓
end = right
```

# 11. 整道题流程

```text
① 统计字符第一次、最后一次出现位置
                ↓
② 得到字符初始区间 [l,r]
                ↓
③ 检查区间里的所有字符
                ↓
④ 某字符范围超出 [l,r] → 扩展区间
                ↓
⑤ 继续检查新扩展区域，直到稳定
                ↓
⑥ 得到所有合法区间 valid
                ↓
⑦ 按 right 从小到大排序
                ↓
⑧ 贪心选择 left > end 的区间
                ↓
⑨ 得到最多的不重叠子字符串
```

## 最终记忆

这题可以浓缩成两个核心思想：

**区间扩展：**

> 包含一个字符，就必须包含这个字符的所有出现位置。

**区间贪心：**

> 想选最多的不重叠区间，就优先选择结束得最早的区间。

变量记忆：

```text
l/r   → 区间边界
nl/nr → 扫描位置
end   → 上一个已选择区间的右端点
```
