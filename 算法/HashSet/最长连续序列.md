### LeetCode 128：最长连续序列

**思路：** 用 `HashSet` 去重；只从序列起点（不存在 `num - 1`）开始向后查找。

```java
class Solution {
    public int longestConsecutive(int[] nums) {
        Set<Integer> set = new HashSet<>();
        for (int num : nums) set.add(num);

        int max = 0;
        for (int num : set) {
            if (!set.contains(num - 1)) {
                int current = num, length = 1;
                while (set.contains(current + 1)) {
                    current++;
                    length++;
                }
                max = Math.max(max, length);
            }
        }
        return max;
    }
}
```

**易错点：**

- 增强 `for` 中的 `num` 是元素，不是下标：写 `set.add(num)`。
- 空数组应返回 `0`，因此 `max` 初始化为 `0`。
- 必须判断 `!set.contains(num - 1)`，否则重复向后查找，最坏为 `O(n²)`。
- `HashSet` 用于去重，`add/contains` 平均为 `O(1)`。
- 时间复杂度 `O(n)`，空间复杂度 `O(n)`。
