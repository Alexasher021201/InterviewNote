可以把这两个操作分开理解：

**启动 Container** 和 **进入 Container** 是两件事。

### 1. 先查看 Container ID

查看所有容器，包括已经退出的：

```powershell
docker ps -a
```

例如：

```text
CONTAINER ID   IMAGE    STATUS                    NAMES
a12b34c56d78   ubuntu   Exited (0) 2 minutes ago  my-ubuntu
```

那么 Container ID 就是：

```text
a12b34c56d78
```

实际上通常只写前几位就够了，只要能唯一确定：

```powershell
docker start a12b
```

---

### 2. Container 已经 Exit，如何重新启动？

使用：

```powershell
docker start <container_id>
```

例如：

```powershell
docker start a12b34c56d78
```

然后查看：

```powershell
docker ps
```

如果它正在运行，就能看到它。

不过这里有一个很重要的坑：**`docker start` 不保证容器会一直处于 Running。**

比如 `hello-world`：

```powershell
docker start <hello-world的container_id>
```

它会：

```text
启动
 ↓
打印 Hello from Docker!
 ↓
程序执行完毕
 ↓
再次 Exit
```

因为容器是否存活，取决于它的**主进程是否还在运行**。

---

### 3. 如何进入正在运行的 Container？

最常用：

```powershell
docker exec -it <container_id> bash
```

例如：

```powershell
docker exec -it a12b34c56d78 bash
```

然后你会看到类似：

```text
root@a12b34c56d78:/#
```

说明你已经进入这个 Ubuntu Container。

如果容器没有 `bash`，可以尝试：

```powershell
docker exec -it a12b34c56d78 sh
```

退出：

```bash
exit
```

---

### 4. Exit 的 Ubuntu 容器，想启动并直接进入

还有一个很好用的命令：

```powershell
docker start -ai <container_id>
```

例如：

```powershell
docker start -ai a12b34c56d78
```

这里：

```text
-a → attach，连接到容器输出
-i → interactive，保持交互输入
```

所以对于你之前这样创建的 Ubuntu：

```powershell
docker run -it ubuntu bash
```

进入 Ubuntu 后：

```text
root@xxxx:/#
```

如果你执行：

```bash
exit
```

Ubuntu 容器就退出了。

之后想重新进去：

```powershell
docker ps -a
```

找到 ID：

```powershell
docker start -ai <container_id>
```

就可以继续使用原来的 Ubuntu 容器。

---

### 5. `docker start` 和 `docker exec` 的区别

这个非常重要：

```text
docker start
     │
     │ 启动
     ↓
Container
     │
     │ 进入已经运行的 Container
     ↓
docker exec -it xxx bash
```

所以：

| 需求 | 命令 |
|---|---|
| 查看正在运行的容器 | `docker ps` |
| 查看所有容器 | `docker ps -a` |
| 启动已退出容器 | `docker start ID` |
| 启动并连接原来的交互程序 | `docker start -ai ID` |
| 进入正在运行的容器 | `docker exec -it ID bash` |
| 停止容器 | `docker stop ID` |
| 删除容器 | `docker rm ID` |

对于你目前学习 Docker，**最值得记住的就是这套流程：**

```powershell
# 第一次创建 Ubuntu
docker run -it ubuntu bash

# 在 Ubuntu 里面
root@xxx:/# exit

# 查看刚才退出的容器
docker ps -a

# 重新启动并进入原来的 Ubuntu
docker start -ai <container_id>
```

注意 **`docker run` 是“创建一个新容器 + 启动它”**，而 **`docker start` 是“重新启动已经存在的容器”**。这是 Docker 初学阶段非常容易混淆的一点。
