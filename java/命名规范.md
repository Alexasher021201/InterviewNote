Java 常用命名规范基本遵循这一套：

| 场景 | 规范 | 示例 |
|---|---|---|
| 类、接口、枚举、注解 | 大驼峰（PascalCase） | `UserService`、`Runnable`、`OrderStatus` |
| 方法 | 小驼峰（camelCase） | `getUserName()`、`calculateTotal()` |
| 普通变量、参数 | 小驼峰 | `userName`、`totalPrice` |
| 常量（`static final`） | 全大写 + 下划线 | `MAX_RETRY_COUNT`、`DEFAULT_TIMEOUT` |
| 包名 | 全小写，通常用域名倒序 | `com.example.project.service` |
| 枚举常量 | 全大写 + 下划线 | `PENDING_PAYMENT`、`SUCCESS` |
| 泛型类型参数 | 简短的大写字母 | `T`、`E`、`K`、`V` |
| 布尔变量 / 方法 | 用 `is`、`has`、`can` 等开头 | `isActive`、`hasPermission()`、`canDelete()` |

例如：

```java
package com.example.user;

public class UserService {

    private static final int MAX_LOGIN_ATTEMPTS = 5;

    private String userName;
    private boolean active;

    public UserService(String userName) {
        this.userName = userName;
    }

    public boolean isActive() {
        return active;
    }

    public void updateUserName(String newUserName) {
        this.userName = newUserName;
    }
}
```

几个容易混淆的点：

- 类名用名词：`User`、`OrderService`
- 方法名通常用动词开头：`saveUser()`、`findById()`、`deleteOrder()`
- 布尔值避免 `isIsActive` 这种重复写法。字段用 `active`，方法用 `isActive()` 更自然。
- 缩写尽量也按驼峰处理：`HttpClient`、`UrlParser`、`XmlReader`，不要写 `HTTPClient`、`URLParser`。
- 包名一般不用下划线，也不要大写：`com.example.order.service`。
