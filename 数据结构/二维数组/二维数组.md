# 1. 二维数组最重要的理解

Java：

```java
int[][] nums;
```

本质上可以理解为：

> **一个数组，里面的每个元素又是一个 `int[]`。**

例如：

```java
int[][] nums = {
    {1, 2},
    {3, 4},
    {5, 6}
};
```

结构：

```text
nums
 │
 ├── nums[0] → [1, 2]
 ├── nums[1] → [3, 4]
 └── nums[2] → [5, 6]
```

因此一定记住类型关系：

```text
nums       → int[][]
nums[i]    → int[]
nums[i][j] → int
```

这是理解二维数组、二维数组排序和 `List<int[]>` 的基础。

# 3. 一维数组的创建语法：重点薄弱点

Java **不能**写：

```java
int[] nums = [1, 2]; // ❌
```

Java 使用：

```java
int[] nums = {1, 2}; // ✅
```

但是 `{}` 简写主要用于**声明时初始化**。

例如：

```java
int[] nums;

nums = {1, 2}; // ❌
```

应该：

```java
nums = new int[]{1, 2}; // ✅
```

所以 LeetCode 中经常看到：

```java
new int[]{left, right}
```

例如：

```java
int[] current = new int[]{1, 3};

current = new int[]{1, 6};
```

### 必须记住

```text
[a, b]            ❌ Java 不支持

int[] a = {1, 2}; ✅ 声明时可以

new int[]{1, 2}   ✅ 通用写法
```

# 8. 二维数组按照某一列排序

这是目前非常重要的 LeetCode 技能。

假设：

```java
int[][] intervals = {
    {8, 10},
    {1, 3},
    {2, 6}
};
```

按照第 `0` 列升序：

```java
Arrays.sort(
    intervals,
    (a, b) -> Integer.compare(a[0], b[0])
);
```

结果：

```text
[1,3]
[2,6]
[8,10]
```

---

## 为什么 a、b 可以使用 a[0]？

因为：

```java
intervals
```

是：

```text
int[][]
```

所以里面每个元素：

```java
intervals[i]
```

都是：

```text
int[]
```

Comparator 中：

```java
(a, b)
```

本质就是两个 `int[]`。

例如：

```text
a = [1,3]
b = [2,6]
```

因此：

```java
a[0] → 1
a[1] → 3

b[0] → 2
b[1] → 6
```

# 9. 常见二维数组排序写法

## 第 0 列升序

```java
Arrays.sort(
    nums,
    (a, b) -> Integer.compare(a[0], b[0])
);
```

## 第 1 列升序

```java
Arrays.sort(
    nums,
    (a, b) -> Integer.compare(a[1], b[1])
);
```

## 第 1 列降序

```java
Arrays.sort(
    nums,
    (a, b) -> Integer.compare(b[1], a[1])
);
```

记忆：

```text
a 在前 → 升序

b 在前 → 降序
```

推荐使用 `Integer.compare()`，而不是：

```java
a[0] - b[0]
```

避免极端情况下整数溢出。

# 10. LeetCode 1710：二维数组 + 贪心

`boxTypes[i]`：

```text
[箱子数量, 每箱单元数]
```

所以：

```java
boxTypes[i][0] → 箱子数量

boxTypes[i][1] → 每箱单元数
```

为了最大化单元数：

> 每个箱子占用空间相同，所以优先选择“每箱单元数”最大的箱子。

因此：

```java
Arrays.sort(
    boxTypes,
    (a, b) -> Integer.compare(b[1], a[1])
);
```

也就是：

> 按第 1 列降序。

这道题需要记住的不是答案，而是：

```text
二维数组每一行代表一组数据
        ↓
找到排序关键字段
        ↓
根据某一列排序
```

# 12. 合并区间的核心思想

不要单纯理解成：

> “前一个区间”和“后一个区间”比较。

更准确的是：

> **维护一个当前正在合并的区间 `currentMerge`。**

例如：

```text
[1,3]
[2,6]
[5,10]
```

过程：

```text
current = [1,3]

↓ 和 [2,6] 合并

current = [1,6]

↓ 和 [5,10] 合并

current = [1,10]
```

所以比较：

```java
if (currentMerge[1] >= intervals[i][0])
```

意思：

```text
当前右端点 >= 下一个左端点
```

说明发生重叠。

---

# 13. 合并右端点使用 Math.max

例如：

```text
current = [1,10]

next = [2,6]
```

合并结果仍然：

```text
[1,10]
```

所以不能直接：

```java
currentMerge[1] = intervals[i][1];
```

而应该：

```java
currentMerge[1] =
    Math.max(currentMerge[1], intervals[i][1]);
```

核心：

```text
合并后的：

左端点 → 当前左端点

右端点 → 两个右端点的最大值
```

# 14. 区间合并标准结构

```java
Arrays.sort(
    intervals,
    (a, b) -> Integer.compare(a[0], b[0])
);

List<int[]> result = new ArrayList<>();

int[] current = new int[]{
    intervals[0][0],
    intervals[0][1]
};

for (int i = 1; i < intervals.length; i++) {

    if (current[1] >= intervals[i][0]) {

        current[1] =
            Math.max(current[1], intervals[i][1]);

    } else {

        result.add(current);

        current = new int[]{
            intervals[i][0],
            intervals[i][1]
        };
    }
}

result.add(current);
```

最后这一句：

```java
result.add(current);
```

非常容易漏。

因为循环结束以后：

> 最后一个正在处理的区间还没有加入结果。
