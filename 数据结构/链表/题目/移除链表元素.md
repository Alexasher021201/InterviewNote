# LeetCode 203：移除链表元素

## 1. 我的错误写法

```java
ListNode index = head;

while (index.next != null) {
    if (index.next.val == val) {
        index.next = index.next.next;
    }
    index = index.next;
}
```

主要有三个问题：

- **无法删除 `head`**：始终检查 `index.next`，没有检查头节点本身。
- **连续目标节点会漏删**：删除 `index.next` 后又立刻移动 `index`，会跳过节点。
- **`head == null` 时空指针**：直接访问 `index.next` 会报错。

---

## 2. 正确写法：Dummy Node

```java
class Solution {
    public ListNode removeElements(ListNode head, int val) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;

        ListNode index = dummy;

        while (index.next != null) {
            if (index.next.val == val) {
                index.next = index.next.next;
            } else {
                index = index.next;
            }
        }

        return dummy.next;
    }
}
```

核心结构：

```text
dummy
  ↓
  0 -> 1 -> 2 -> 6 -> 3
       ↑
      head
```

有了 `dummy`，即使需要删除 `head`，也可以统一使用：

```java
index.next = index.next.next;
```

---

## 3. 困惑一：为什么有 dummy 还需要 index？

```java
ListNode index = dummy;
```

不是创建新的节点，而是让两个引用指向**同一个节点**：

```text
dummy
  \
   ↓
   0 -> 1 -> 2 -> 3
   ↑
  /
index
```

二者职责不同：

```text
dummy：锚点，永远留在链表最前面
index：工作指针，负责向后遍历和删除
```

当：

```java
index = index.next;
```

只有 `index` 移动：

```text
dummy
 ↓
 0 -> 1 -> 2 -> 3
      ↑
    index
```

`dummy` 仍然留在原地，因此最后还能通过它找到整个链表。

**记忆：dummy 守家，index 干活。**

---

## 4. 困惑二：为什么 return dummy.next 而不是 head？

因为 `head` 保存的是**原来的头节点**，而原头节点可能被删除。

例如：

```text
head = [6,1,2]
val = 6
```

开始：

```text
dummy
 ↓
 0 -> 6 -> 1 -> 2
      ↑
     head
```

删除 `6`：

```java
dummy.next = dummy.next.next;
```

之后：

```text
dummy
 ↓
 0 -----> 1 -> 2

      6 -> 1 -> 2
      ↑
     head
```

此时：

```text
head       -> 6
dummy.next -> 1
```

所以：

```java
return head;       // ❌ 可能还是旧头节点
return dummy.next; // ✅ 最终真正的头节点
```

### 关键理解

```java
dummy.next = head;
```

只是让两个引用**暂时指向同一个节点**，并不是永久绑定。

修改：

```java
dummy.next = ...
```

不会自动修改 `head`。

---

## 5. 为什么删除后 index 不能移动？

例如：

```text
1 -> 6 -> 6 -> 2
↑
index
```

删除第一个 `6`：

```java
index.next = index.next.next;
```

得到：

```text
1 -----> 6 -> 2
↑
index
```

新的 `index.next` 仍然可能需要删除，所以 `index` 必须留在原地继续检查。

因此模板是：

```java
if (index.next.val == val) {
    index.next = index.next.next; // 删除，index不动
} else {
    index = index.next;           // 不删除，才往后走
}
```

## 6. 最终记忆

### Dummy Node 的作用

> **把“删除头节点”转化成普通的“删除下一个节点”。**

### 三个引用的职责

```text
head  ：原来的头节点
dummy ：固定锚点，不移动
index ：工作指针，负责遍历
```

### 删除链表节点的高频模板

```java
if (需要删除 index.next) {
    index.next = index.next.next;
    // index 不动！
} else {
    index = index.next;
}
```

### 一句话记忆

> **dummy 守住入口，index 负责干活；删除 next 后原地检查，不删除才继续前进；最后返回 dummy.next。**
