## 1. 什么是二叉树

二叉树（Binary Tree）是一种树形数据结构。每个节点最多有两个子节点：

-   左孩子：`left`
-   右孩子：`right`

典型结构：

``` text
        1
       / \
      2   3
     / \
    4   5
```

节点 `1` 是根节点（root）。

节点 `2`、`3` 是 `1` 的孩子。

节点 `4`、`5`、`3` 没有孩子，因此是叶子节点（leaf）。

## 2. Java 中最常见的 TreeNode

LeetCode 中通常会直接提供：

``` java
public class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode() {}

    TreeNode(int val) {
        this.val = val;
    }

    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}
```

最重要的是理解：

``` java
root.val
root.left
root.right
```

例如：

``` text
        10
       /  \
      5    20
```

那么：

``` java
root.val == 10
root.left.val == 5
root.right.val == 20
```

如果 `5` 是叶子节点：

``` java
root.left.left == null
root.left.right == null
```

## 3. null 是二叉树题目的核心

假设：

``` java
TreeNode root
```

`root == null` 表示当前位置没有节点。

例如：

``` text
    1
     \
      2
```

节点 `1`：

``` text
left  = null
right = 节点2
```

节点 `2`：

``` text
left  = null
right = null
```

### 判断叶子节点

``` java
if (root.left == null && root.right == null) {
    // root 是叶子节点
}
```

叶子节点必须左右孩子都不存在。

# 4. 二叉树最重要的思想：递归

很多二叉树题，本质上都可以理解为：

> 当前节点要解决的问题，可以拆成左子树的问题和右子树的问题。

例如计算节点数量：

``` java
public int count(TreeNode root) {
    if (root == null) {
        return 0;
    }

    int left = count(root.left);
    int right = count(root.right);

    return left + right + 1;
}
```

结构：

``` text
count(root)
    |
    +-- count(root.left)
    |
    +-- count(root.right)
    |
    +-- 左边 + 右边 + 当前节点
```

# 5. 万能递归模板

建议首先熟悉这个结构：

``` java
public ReturnType dfs(TreeNode root) {
    // 1. 递归终止条件
    if (root == null) {
        return ...;
    }

    // 2. 处理左子树
    ReturnType left = dfs(root.left);

    // 3. 处理右子树
    ReturnType right = dfs(root.right);

    // 4. 根据左右子树结果计算当前节点答案
    return ...;
}
```

例如最大深度：

``` java
public int maxDepth(TreeNode root) {
    if (root == null) {
        return 0;
    }

    int leftDepth = maxDepth(root.left);
    int rightDepth = maxDepth(root.right);

    return Math.max(leftDepth, rightDepth) + 1;
}
```

记忆：

``` text
当前树高度
=
max(左子树高度, 右子树高度)
+ 当前这一层
```

# 6. 为什么递归一定要写终止条件

例如：

``` java
dfs(root.left);
```

最终一定会走到叶子节点。

叶子：

``` text
    5
   / \
 null null
```

继续：

``` java
dfs(root.left);
```

实际上就是：

``` java
dfs(null);
```

所以通常必须写：

``` java
if (root == null) {
    return;
}
```

或者：

``` java
if (root == null) {
    return 0;
}
```

具体返回什么取决于题目。

# 7. 二叉树的三种 DFS 遍历

最重要的是：

1.  前序遍历
2.  中序遍历
3.  后序遍历

区别只有：

> 当前节点 `root` 在什么时候处理。

------------------------------------------------------------------------

## 7.1 前序遍历

顺序：

``` text
根 → 左 → 右
```

代码：

``` java
public void preorder(TreeNode root) {
    if (root == null) {
        return;
    }

    System.out.println(root.val);
    preorder(root.left);
    preorder(root.right);
}
```

例如：

``` text
        1
       / \
      2   3
     / \
    4   5
```

结果：

``` text
1 2 4 5 3
```

可以记：

``` java
处理 root
递归 left
递归 right
```

------------------------------------------------------------------------

## 7.2 中序遍历

顺序：

``` text
左 → 根 → 右
```

代码：

``` java
public void inorder(TreeNode root) {
    if (root == null) {
        return;
    }

    inorder(root.left);
    System.out.println(root.val);
    inorder(root.right);
}
```

结果：

``` text
4 2 5 1 3
```

### 高频知识点

对于二叉搜索树 BST：

> 中序遍历通常会得到递增序列。

这是非常高频的性质。

------------------------------------------------------------------------

## 7.3 后序遍历

顺序：

``` text
左 → 右 → 根
```

代码：

``` java
public void postorder(TreeNode root) {
    if (root == null) {
        return;
    }

    postorder(root.left);
    postorder(root.right);
    System.out.println(root.val);
}
```

结果：

``` text
4 5 2 3 1
```

后序特别适合：

> 当前节点的答案依赖左右孩子的答案。

例如：

-   最大深度
-   判断平衡二叉树
-   二叉树直径
-   树形 DP

# 8. 一个非常重要的理解：代码位置决定遍历顺序

### 前序

``` java
visit(root);

dfs(root.left);
dfs(root.right);
```

### 中序

``` java
dfs(root.left);

visit(root);

dfs(root.right);
```

### 后序

``` java
dfs(root.left);
dfs(root.right);

visit(root);
```

所以不要死记三个名字，记住：

> `visit(root)` 写在哪里，就是什么顺序。

# 11. BFS 通用模板

``` java
public void bfs(TreeNode root) {
    if (root == null) {
        return;
    }

    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);

    while (!queue.isEmpty()) {
        TreeNode node = queue.poll();

        System.out.println(node.val);

        if (node.left != null) {
            queue.offer(node.left);
        }

        if (node.right != null) {
            queue.offer(node.right);
        }
    }
}
```

# 12. 按层处理：超级高频模板

很多题需要知道：

> 当前这一层有多少节点？

关键：

``` java
int size = queue.size();
```

完整模板：

``` java
public void levelOrder(TreeNode root) {
    if (root == null) {
        return;
    }

    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);

    while (!queue.isEmpty()) {

        int size = queue.size();

        for (int i = 0; i < size; i++) {

            TreeNode node = queue.poll();

            System.out.println(node.val);

            if (node.left != null) {
                queue.offer(node.left);
            }

            if (node.right != null) {
                queue.offer(node.right);
            }
        }
    }
}
```

为什么必须先保存：

``` java
int size = queue.size();
```

因为处理当前层时，你会不断把下一层节点加入 `queue`。

如果直接动态使用 `queue.size()`，大小会发生变化。

# 13. 层序遍历返回 List\<List`<Integer>`{=html}\>

这是 LeetCode 非常经典的写法：

``` java
public List<List<Integer>> levelOrder(TreeNode root) {

    List<List<Integer>> result = new ArrayList<>();

    if (root == null) {
        return result;
    }

    Queue<TreeNode> queue = new ArrayDeque<>();
    queue.offer(root);

    while (!queue.isEmpty()) {

        int size = queue.size();
        List<Integer> level = new ArrayList<>();

        for (int i = 0; i < size; i++) {

            TreeNode node = queue.poll();

            level.add(node.val);

            if (node.left != null) {
                queue.offer(node.left);
            }

            if (node.right != null) {
                queue.offer(node.right);
            }
        }

        result.add(level);
    }

    return result;
}
```

最终：

``` text
[
    [1],
    [2,3],
    [4,5]
]
```

# 14. 二叉树最大深度

这是最值得掌握的递归题之一。

``` java
public int maxDepth(TreeNode root) {

    if (root == null) {
        return 0;
    }

    int left = maxDepth(root.left);
    int right = maxDepth(root.right);

    return Math.max(left, right) + 1;
}
```

思考：

``` text
        root
       /    \
    left    right
```

如果：

``` text
左边深度 = 3
右边深度 = 5
```

那么：

``` text
当前深度 = max(3,5) + 1 = 6
```

# 15. 判断两棵树是否相同

非常经典的"双树递归"。

``` java
public boolean isSameTree(TreeNode p, TreeNode q) {

    if (p == null && q == null) {
        return true;
    }

    if (p == null || q == null) {
        return false;
    }

    if (p.val != q.val) {
        return false;
    }

    return isSameTree(p.left, q.left)
        && isSameTree(p.right, q.right);
}
```

三个判断非常值得记：

``` java
p == null && q == null
```

两个都没节点 → 相同。

``` java
p == null || q == null
```

只有一个没节点 → 不同。

``` java
p.val != q.val
```

值不同 → 不同。

# 16. 判断对称二叉树

例如：

``` text
        1
       / \
      2   2
     / \ / \
    3  4 4  3
```

核心不是：

``` text
left.left 对 right.left
```

而是镜像比较：

``` text
left.left  ↔ right.right
left.right ↔ right.left
```

代码：

``` java
public boolean isSymmetric(TreeNode root) {
    if (root == null) {
        return true;
    }

    return compare(root.left, root.right);
}

public boolean compare(TreeNode left, TreeNode right) {

    if (left == null && right == null) {
        return true;
    }

    if (left == null || right == null) {
        return false;
    }

    if (left.val != right.val) {
        return false;
    }

    return compare(left.left, right.right)
        && compare(left.right, right.left);
}
```

# 17. 路径类问题

很多题会问：

-   是否存在路径和
-   所有根到叶路径
-   路径上的节点
-   最大路径和

这种题经常需要携带额外参数：

``` java
dfs(root, currentSum);
```

例如判断是否存在根到叶子的路径和：

``` java
public boolean hasPathSum(TreeNode root, int targetSum) {

    if (root == null) {
        return false;
    }

    if (root.left == null && root.right == null) {
        return targetSum == root.val;
    }

    return hasPathSum(root.left, targetSum - root.val)
        || hasPathSum(root.right, targetSum - root.val);
}
```

这里非常重要：

> 题目要求的是"根节点到叶子节点"。

所以不能只判断：

``` java
targetSum == root.val
```

还必须：

``` java
root.left == null && root.right == null
```

# 18. 回溯：记录路径

例如记录当前路径：

``` java
List<Integer> path = new ArrayList<>();
```

进入节点：

``` java
path.add(root.val);
```

递归：

``` java
dfs(root.left, path);
dfs(root.right, path);
```

离开节点：

``` java
path.remove(path.size() - 1);
```

典型结构：

``` java
public void dfs(TreeNode root, List<Integer> path) {

    if (root == null) {
        return;
    }

    // 做选择
    path.add(root.val);

    dfs(root.left, path);
    dfs(root.right, path);

    // 撤销选择
    path.remove(path.size() - 1);
}
```

记忆：

``` text
进入节点 → add
递归孩子
离开节点 → remove
```

这就是二叉树中的回溯思想。

# 19. 二叉搜索树 BST

BST 是一种特殊二叉树。

通常满足：

``` text
左子树节点值 < 当前节点值 < 右子树节点值
```

例如：

``` text
        5
       / \
      3   8
     / \ / \
    2  4 6  9
```

非常重要的性质：

> BST 的中序遍历得到有序序列。

中序：

``` text
2 3 4 5 6 8 9
```

因此看到：

-   BST 第 k 小
-   BST 是否有效
-   BST 最小差值
-   BST 众数

要优先想到：

``` text
中序遍历
```

------------------------------------------------------------------------

# 20. BST 查找

``` java
public TreeNode searchBST(TreeNode root, int val) {

    if (root == null) {
        return null;
    }

    if (root.val == val) {
        return root;
    }

    if (val < root.val) {
        return searchBST(root.left, val);
    }

    return searchBST(root.right, val);
}
```

BST 不需要左右两边都搜索。

因为：

``` text
val < root.val → 只可能在左边
val > root.val → 只可能在右边
```

------------------------------------------------------------------------

# 21. BST 插入

``` java
public TreeNode insertIntoBST(TreeNode root, int val) {

    if (root == null) {
        return new TreeNode(val);
    }

    if (val < root.val) {
        root.left = insertIntoBST(root.left, val);
    } else {
        root.right = insertIntoBST(root.right, val);
    }

    return root;
}
```

这里有一个非常重要的写法：

``` java
root.left = insertIntoBST(root.left, val);
```

而不是单纯：

``` java
insertIntoBST(root.left, val);
```

因为递归可能创建新的节点，你需要把返回的新子树重新接到 `root.left` 上。

# 24. 前序、中序、后序到底什么时候用

可以这样理解。

## 前序：从父节点向孩子传递信息

``` text
根 → 左 → 右
```

适合：

-   路径记录
-   复制树
-   从上往下传状态
-   序列化等

------------------------------------------------------------------------

## 后序：从孩子向父节点返回信息

``` text
左 → 右 → 根
```

适合：

-   高度
-   节点数量
-   平衡树
-   二叉树直径
-   树形 DP

如果题目出现：

> "根据左右子树的答案计算当前节点答案"

优先考虑后序。

------------------------------------------------------------------------

## 中序：BST 高频

``` text
左 → 根 → 右
```

尤其适合：

-   BST
-   第 k 小
-   判断 BST
-   有序节点处理

# 28. 非常常见的错误

## 错误 1：访问 null 的属性

错误：

``` java
if (root.left.val == 10)
```

如果：

``` java
root.left == null
```

就会产生：

``` text
NullPointerException
```

应该先判断：

``` java
if (root.left != null && root.left.val == 10)
```

------------------------------------------------------------------------

## 错误 2：忘记递归终止条件

``` java
public void dfs(TreeNode root) {
    dfs(root.left);
    dfs(root.right);
}
```

当 `root == null` 时继续访问：

``` java
root.left
```

就会报错。

应该：

``` java
if (root == null) {
    return;
}
```

------------------------------------------------------------------------

## 错误 3：叶子节点判断使用 \|\|

错误：

``` java
if (root.left == null || root.right == null)
```

这代表：

> 至少一个孩子为空。

不一定是叶子。

正确：

``` java
if (root.left == null && root.right == null)
```

------------------------------------------------------------------------

## 错误 4：BFS 忘记判断孩子是否为空

通常不要：

``` java
queue.offer(node.left);
queue.offer(node.right);
```

更安全的常见写法：

``` java
if (node.left != null) {
    queue.offer(node.left);
}

if (node.right != null) {
    queue.offer(node.right);
}
```

尤其 `ArrayDeque` 不允许加入 `null`。

------------------------------------------------------------------------

## 错误 5：层序遍历直接在 for 条件里使用 queue.size()

不推荐：

``` java
for (int i = 0; i < queue.size(); i++)
```

因为循环过程中：

``` java
queue.offer(...)
```

会改变 `queue.size()`。

应该先：

``` java
int size = queue.size();

for (int i = 0; i < size; i++) {
    ...
}
```

# 30. 最值得背下来的 4 个模板

## 模板 1：普通 DFS

``` java
public void dfs(TreeNode root) {

    if (root == null) {
        return;
    }

    // 当前节点

    dfs(root.left);
    dfs(root.right);
}
```

------------------------------------------------------------------------

## 模板 2：需要返回结果的 DFS

``` java
public int dfs(TreeNode root) {

    if (root == null) {
        return 0;
    }

    int left = dfs(root.left);
    int right = dfs(root.right);

    return ...;
}
```

------------------------------------------------------------------------

## 模板 3：BFS 层序遍历

``` java
Queue<TreeNode> queue = new ArrayDeque<>();

if (root != null) {
    queue.offer(root);
}

while (!queue.isEmpty()) {

    int size = queue.size();

    for (int i = 0; i < size; i++) {

        TreeNode node = queue.poll();

        if (node.left != null) {
            queue.offer(node.left);
        }

        if (node.right != null) {
            queue.offer(node.right);
        }
    }
}
```

------------------------------------------------------------------------

## 模板 4：路径回溯

``` java
public void dfs(TreeNode root, List<Integer> path) {

    if (root == null) {
        return;
    }

    path.add(root.val);

    dfs(root.left, path);
    dfs(root.right, path);

    path.remove(path.size() - 1);
}
```

## 最核心的一句话

不要把二叉树理解成大量不同的题型。

大部分二叉树题都在重复同一件事：

``` text
来到当前节点
    ↓
处理左子树
    ↓
处理右子树
    ↓
利用左右子树的信息
解决当前节点的问题
```

真正需要熟练的是：

**"我这个递归函数到底代表什么？"**

一旦函数定义清楚，`null` 的返回值、左右递归以及最后的 `return`
往往都会自然地确定下来。
