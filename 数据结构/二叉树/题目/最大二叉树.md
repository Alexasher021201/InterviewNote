# LeetCode 654 最大二叉树｜错题复盘

## 1. 题目核心思路

对于数组：

```text
[3,2,1,6,0,5]
```

构造最大二叉树：

1. 找当前数组最大值作为根节点。
2. 最大值左边的数据递归构造左子树。
3. 最大值右边的数据递归构造右子树。

```text
[3,2,1]   6   [0,5]
    ↓      ↓      ↓
  左子树   root   右子树
```

核心递归思想：

```text
当前最大值 → 当前节点
最大值左边 → 左子树
最大值右边 → 右子树
```

# 2. 错误一：`new int[]{}` 不是动态数组

曾写：

```java
int[] array = new int[]{};

array[0] = nums[0]; // ❌
```

`new int[]{}` 创建的是：

> **长度为 0 的数组。**

数组创建后长度固定，不能像 `ArrayList` 一样动态添加。

```java
new int[3]
```

才表示创建长度为 3 的数组：

```text
[0, 0, 0]
```

### 记忆

```text
ArrayList → 可以动态 add()

数组 → 创建时长度就固定
```

---

# 3. 错误二：子数组长度不能直接用 nums.length

曾写：

```java
int[] left = new int[nums.length];
int[] right = new int[nums.length];
```

假设：

```text
nums = [3,2,1,6,0,5]
index = 3
```

真正需要：

```text
left  = [3,2,1] → 长度 3
right = [0,5]   → 长度 2
```

所以：

```java
int[] left = new int[index];

int[] right =
    new int[nums.length - index - 1];
```

否则多出来的位置会被 Java 默认初始化为 `0`，污染递归数据。

# 4. 错误三：`root.left` 默认是 null

创建：

```java
TreeNode root = new TreeNode(6);
```

实际得到：

```text
      6
     / \
  null null
```

所以直接：

```java
addTree(root.left, nums);
```

实际上相当于：

```java
addTree(null, nums);
```

如果递归内部：

```java
root.val = max;
```

就相当于：

```java
null.val = max;
```

产生：

```text
NullPointerException
```

### 关键认识

```text
root.left 的类型是 TreeNode

≠

root.left 一定存在 TreeNode
```

它完全可能是 `null`。

# 5. 错误四：不能无条件 `new TreeNode()`

为了解决上面的 NPE，又写成：

```java
root.left = new TreeNode();
root.right = new TreeNode();

addTree(root.left, left);
addTree(root.right, right);
```

这又会产生新的问题：

> 即使没有左/右子树，也强行创建了节点。

例如当前只有：

```text
[1]
```

正确应该：

```text
    1
   / \
 null null
```

如果执行：

```java
root.left = new TreeNode();
root.right = new TreeNode();
```

就变成：

```text
    1
   / \
  0   0
```

因为：

```java
new TreeNode()
```

是真的创建了节点，而 `int val` 默认值是 `0`。

# 6. `null` 和 `new TreeNode()` 必须区分

这是本题最重要的薄弱点。

### null

```java
TreeNode node = null;
```

表示：

```text
没有节点
```

### new TreeNode()

```java
TreeNode node = new TreeNode();
```

表示：

```text
真的存在一个节点

val   = 0
left  = null
right = null
```

### new TreeNode(5)

```java
TreeNode node = new TreeNode(5);
```

表示：

```text
真的存在一个节点

val   = 5
left  = null
right = null
```

所以：

> **`new TreeNode()` 不是创建一个“空位置”，而是真的往树里创建了一个节点。**

---

# 7. 正确的节点创建原则

```text
有数据
 ↓
创建 TreeNode
 ↓
继续递归

没有数据
 ↓
不要创建节点
 ↓
保持 null
```

如果继续使用 `void addTree()` 的写法：

```java
if (left.length > 0) {
    root.left = new TreeNode();
    addTree(root.left, left);
}

if (right.length > 0) {
    root.right = new TreeNode();
    addTree(root.right, right);
}
```

# 8. 更推荐：让递归返回 TreeNode

构造二叉树更自然的写法是：

```java
TreeNode build(...) {

    if (没有数据) {
        return null;
    }

    TreeNode root = new TreeNode(...);

    root.left = build(...);
    root.right = build(...);

    return root;
}
```

核心理解：

```java
root.left = build(...);
```

不是简单的：

> “递归一下左边。”

而是：

> **让递归帮我构造完整的左子树，并把左子树根节点返回给 `root.left`。**

同理：

```java
root.right = build(...);
```

# 9. 本题最值得记住的递归模板

以后遇到：

- 构造二叉树
- 构造 BST
- 插入树节点
- 根据遍历结果还原二叉树

要对下面结构敏感：

```java
public TreeNode build(...) {

    if (终止条件) {
        return null;
    }

    TreeNode root = new TreeNode(...);

    root.left = build(...);
    root.right = build(...);

    return root;
}
```

# 10. 本题最终复盘

这次主要暴露了 4 个知识薄弱点：

```text
① 数组长度创建后固定
   new int[]{} 的长度就是 0

② 子数组必须计算正确长度
   不能用原数组长度硬创建

③ root.left / root.right 默认是 null
   TreeNode 类型 ≠ 节点一定存在

④ new TreeNode() 会真的创建节点
   没有子树时应该保持 null
```

最重要的一句话：

> **构造二叉树时，“没有节点”用 `null` 表示；只有确实存在节点时，才应该 `new TreeNode()`。**

以及构造型递归的核心：

```java
root.left = build(...);
root.right = build(...);

return root;
```

这份复习时重点看 **第 4～8 节**即可，基本就是你这道题连续几次报错背后的核心原因。
