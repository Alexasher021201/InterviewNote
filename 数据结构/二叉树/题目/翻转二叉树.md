# LeetCode 226：翻转二叉树

## 1. 核心思路

递归的关键：

> **当前节点只负责交换自己的左右子树，然后让左右子树重复相同操作。**

```text
        1
       / \
      2   3

当前节点 1：
交换左右子树

        1
       / \
      3   2

然后：
→ 递归翻转以 3 为根的子树
→ 递归翻转以 2 为根的子树
```

所以无论树有多深，都可以理解成：

```text
我翻转自己这一层
    ↓
让左子树自己翻转
    ↓
让右子树自己翻转
```

---

## 2. 递归三问

### ① 递归函数的作用是什么？

```java
invertTree(root)
```

表示：

> **把以 `root` 为根的整棵子树翻转，并返回 root。**

### ② 当前节点需要做什么？

交换左右子树：

```java
TreeNode temp = root.left;
root.left = root.right;
root.right = temp;
```

### ③ 下一步交给谁？

让左右子树继续完成同样的事情：

```java
invertTree(root.left);
invertTree(root.right);
```

---

## 3. 完整代码

```java
class Solution {
    public TreeNode invertTree(TreeNode root) {
        if (root == null) {
            return null;
        }

        TreeNode temp = root.left;
        root.left = root.right;
        root.right = temp;

        invertTree(root.left);
        invertTree(root.right);

        return root;
    }
}
```

## 4. 一句话记忆

> **我只负责交换自己的左右孩子，然后告诉左右孩子：你们也照我这样做。**

本质：

```text
大问题：翻转整棵树
        ↓
当前节点交换左右
        ↓
小问题：翻转左子树 + 翻转右子树
```

这就是二叉树递归的典型思想：

> **只考虑当前节点应该做什么，剩下的交给递归。**
